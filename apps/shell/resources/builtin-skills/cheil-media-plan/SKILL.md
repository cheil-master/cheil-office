# 미디어브리프

자료에 있는 사실만 채운다. 자료에 없는 숫자·날짜·이름은 `[확인 필요]`로 남긴다. 기존 공통 칸 이름은 바꾸지 않는다. 실제 광고주 샘플 원문은 포함하지 않는다.

## 작성 기준

기본 정보 → 배경과 커뮤니케이션 과제 → 예산과 집행 조건 → 소재와 랜딩 → 성과 목표와 측정 → 제안 요청과 일정의 순서다. 이 문서는 매체 집행안을 요청하는 브리프다. 임의의 매체 믹스나 효율 수치를 만들지 않는다. 총예산과 매체비·제작비·수수료·VAT 포함 여부를 구분한다. KPI에는 지표의 단위·집계 방식·근거를 함께 적는다. 노란 입력 칸의 자리표시만 채운다.
