# 미디어 플랜

'미디어 플랜' 시트의 5~14행에 매체를 한 줄씩 넣는다. Cheil 문서 원칙을 함께 따른다.

- 사람이 넣는 칸: 매체, 상품·지면, 시작일, 종료일, 예산(원), 예상 노출, 예상 클릭, 비고.
- 회색 칸(CPM, CPC, CTR, 예산 비중)과 합계 줄은 계산식이다. 지우거나 숫자로 덮어쓰지 않는다.
- 견적서에 없는 노출·클릭은 비워 둔다. 비고에 `[확인 필요]`.
- 숫자를 어디서 가져왔는지는 '가정·출처' 시트에 한 줄씩 적는다(자료명, 날짜).
- 1행 제목의 광고주명·캠페인명, 2행의 작성 날짜·팀명을 채운다.
