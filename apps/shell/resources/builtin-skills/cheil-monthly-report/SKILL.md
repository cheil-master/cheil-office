# 결과보고서

자료에 있는 사실만 채운다. 자료에 없는 숫자·날짜·이름은 `[확인 필요]`로 남긴다. 기존 공통 칸 이름은 바꾸지 않는다. 실제 광고주 샘플 원문은 포함하지 않는다.

## 장별 구성

1. 캠페인 결과보고서
2. 결과 요약
3. 캠페인 개요 — 계획 예산  [총예산]
4. 미디어 운영 내용
5. 목표 대비 성과 — [지표 집계 기간과 출처]
6. 매체별 집행 결과 — [매체 데이터 출처와 집계 기준]
7. 소재별 성과 — [소재 비교 기간과 조건]
8. 타깃과 접점별 성과 — 선택 항목 · 연령별 타깃, 노출 위치 등 비교 가능한 데이터가 있을 때 사용한다.
9. 소비자 반응과 추가 효과 — 선택 항목 · 관측된 변화와 캠페인의 인과 효과를 구분한다.
10. 배운 점과 다음 운영 제안
11. 데이터 기준과 확인 사항 — 누락된 값은 0으로 바꾸지 않는다. 서로 다른 매체의 도달 수는 단순 합산하지 않는다.

선택 장은 자료가 없으면 확인 필요로 두고 사용자에게 제외할지 알린다. 빠른 채우기는 칸만 채우므로 자동으로 장 수를 바꾸지 않는다. 반복 장을 복제할 때는 공통 칸 외의 이름에 소재 구분을 붙인다.
