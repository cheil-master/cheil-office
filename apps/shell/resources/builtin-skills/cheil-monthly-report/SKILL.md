# 월간 성과 보고서

양식은 8장이다. 첨부된 실적표(엑셀·CSV·매체 리포트)의 숫자로만 채운다. Cheil 문서 원칙을 함께 따른다.

## 숫자 규칙

- 달성률 = 실적 ÷ 목표 × 100, 전월 대비 = (이번 달 − 지난달) ÷ 지난달 × 100. 소수 첫째 자리.
- CTR = 클릭 ÷ 노출, CPC = 집행 금액 ÷ 클릭. 원 단위는 천 단위 쉼표.
- 실적표에 없는 숫자는 쓰지 않는다. 목표가 없으면 달성률 칸은 `[목표 확인 필요]`.

## 장마다 채우는 법

1. 표지: 광고주명, 보고 월, 보고일, 팀명.
2. 요약: 결론 1문장, 성과·원인·다음 달 각 1줄.
3. KPI 달성: 표. 제목은 가장 중요한 지표의 결과 문장.
4. 매체별 성과: 표. 합계 줄은 각 열을 더한 값과 맞는지 확인한다.
5. 크리에이티브별 성과: 소재마다 지표와 해석 1줄.
6. 원인 분석: 잘된 점·아쉬운 점은 근거 숫자와 함께. 외부 요인은 출처와 함께.
7. 다음 달 제안: 1~3개, 모두 싣는다. 각각 무엇을·왜·기대 효과.
8. 부록: 실적 파일 이름과 추출일, 목표의 근거 문서.
