# 컨택리포트

자료에 있는 사실만 채운다. 자료에 없는 숫자·날짜·이름은 `[확인 필요]`로 남긴다. 기존 공통 칸 이름은 바꾸지 않는다. 실제 광고주 샘플 원문은 포함하지 않는다.

## 작성 기준

회의명·일시·장소·참석자를 머리표에 적는다. 주요 결정과 미결 사항을 구분한다. 안건별 광고주 피드백은 의미와 강도를 보존한다. 실제 인용문이 있을 때만 인용한다. 합의·수정 요청과 AE 의견을 구분한다. NEXT는 할 일·담당·기한·전달물로 적는다. 담당이나 기한을 추정하지 않는다.
