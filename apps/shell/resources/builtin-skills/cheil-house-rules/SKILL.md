# Cheil 문서 원칙

광고주나 사내에 낼 문서를 쓰거나 고칠 때 아래를 지킨다. 사용자가 다르게 말하면 사용자 말을 따른다.

## 숫자와 사실

- 숫자(예산, 노출, 클릭, 전환, 비율, 날짜)는 사용자가 준 자료나 열린 문서에 있는 것만 쓴다. 없으면 지어내지 말고 `[확인 필요: 무엇]`으로 남긴다.
- 계산한 숫자(달성률, 증감, CPM, CPC, CTR)는 식을 한 번 더 확인한다. 비율은 소수 첫째 자리까지.
- 시장 규모·경쟁사 수치·조사 결과는 문장 끝에 `(출처: 자료명, 날짜)`를 붙인다. 출처를 모르면 `[출처 확인 필요]`.
- 추정은 추정이라고 쓴다(“~로 추정”, “가설”).

## 말투

- 장표: 개조식, 명사형으로 끝낸다(예: “20대 신규 유입 확대”). 한 줄 30자 안팎.
- 장표 제목은 결론 문장(헤드 메시지)으로 쓴다. “성과” 대신 “20대 유입, 목표의 112% 달성”.
- 문서 본문: “~다”로 끝내는 평서문. 광고주에게 보내는 인사·메일 문장만 “~합니다”.
- 업계 용어는 그대로 쓴다(KPI, CPM, CTR, ROAS, TVC, OOH, IMC).

## 양식

- 양식 문서를 채울 때는 양식의 순서·제목·표 틀을 지키고 `[ ]` 자리만 채운다. 채울 자료가 없는 자리는 `[확인 필요]`로 둔다.
- 장이나 절을 더하거나 빼야 하면 먼저 이유를 한 줄로 말한다.

## 광고주에게 갈 문서

- `[확인 필요]`, `[ ]`, 작업 메모, AI가 썼다는 표시가 남은 채로 마감하지 않는다. 남은 자리가 있으면 목록으로 사용자에게 알린다.
- 다른 광고주의 이름·자료·숫자를 섞지 않는다.
