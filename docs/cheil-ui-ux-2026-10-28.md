# UI/UX 정리 — 2026-10-28

## 변경 내용

- 홈 검색을 상단 공통 검색줄로 이동했다. 새 캠페인은 ‘내 캠페인’ 제목 옆에, 옵션은 같은 행 오른쪽에 배치했다.
- 홈에 라이트·다크·시스템 설정 버튼을 추가했다. 설정 화면과 같은 저장·변경 알림을 사용한다.
- 왼쪽 탐색기는 기본 208px이며 경계선을 드래그하거나 키보드 좌우 화살표로 폭을 조절할 수 있다. 폭은 프로필에 기억하고 긴 폴더명은 말줄임·전체 경로 툴팁으로 표시한다.
- 캠페인 상세는 최대 1280px의 가로형이다. 수정·폴더·이력 버튼을 위로 옮기고, 정보는 4열, 문서·할 일과 메일 초안은 좌우로 묶었다. 작은 화면에서는 세로로 전환한다.
- 위키·캠페인 옵션을 본문을 밀지 않는 네이티브 팝업으로 바꿨다. 초점 가두기·Esc·바깥 클릭 닫기를 제공하며, 캠페인 안의 팝업만 Esc로 닫으면 캠페인은 유지된다.
- 위키 목록과 문서 상단에 삭제 버튼을, 문서 상단에 편집 버튼을 표시했다. 삭제는 영향 확인 팝업 뒤 기존 버전 확인·휴지통 경로로 처리한다. 원본 파일은 유지한다. 캠페인 연결 제목은 21개 언어에서 정리했다.
- 긴 제목·경로·표·이미지·양식 선택의 너비와 줄바꿈을 제한했다. 날짜 계산의 좁은 화면 입력줄도 쌍별로 나눴다. 문서 편집기와 저장 엔진은 수정하지 않았다.

## 검증

- 셸 타입 검사·빌드·변경 코드 ESLint 오류 0·Prettier·git diff --check 통과. Home.tsx의 기존 quickLookPayload 훅 의존성 경고 1개는 남아 있다.
- 개발 실행본과 최종 배포 실행본 각각에서 38개 화면 점검 통과. 홈·캠페인·위키는 1440·1024·800·720px, 업무 도구 6종과 수식 도우미 6개 모드는 큰 화면과 720px에서 검사했다. 검사한 화면에서 가로 넘침 0건.
- 실제 앱에서 테마 전환, 검색 위치, 탐색기 키보드·드래그 폭 조절, 위키 옵션을 열어도 본문 위치 유지, 문서 편집·저장, 삭제 취소·확인, 캠페인 안 팝업의 Esc 동작을 확인했다.
- 기존 위키 저장·검색·편집·이력 복원 시험 1개 통과. 첫 실행은 90초 제한으로 실패했고, 저장소의 Windows 녹화 정지 대응 옵션 GENOFFICE_E2E_NO_VIDEO=1로 재실행해 11.3초에 통과했다. 제품 코드로 시험을 우회하지 않았다.
- 최종 배포 실행본의 기존 패키지 시험 1개 통과: 편집기 8종·미디어브리프·위키·제품 안내.
- 자료는 모두 가상 캠페인·가상 위키였다. 실제 AI·Azure 서비스는 호출하지 않았다.

전체 저장소의 모든 시험이나 모든 문서 편집·내보내기 조합을 검증한 것은 아니다. 실제 설치·삭제·업그레이드·회사 보안 정책과 실제 Azure OCR 품질은 확인 필요다. 설치·커밋·푸시·외부 게시는 하지 않았다.
