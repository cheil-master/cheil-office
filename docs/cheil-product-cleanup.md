# CheilOffice 안내·설정·배포 고지 정비

2026-10-27. 사용자가 이음오피스와 겹치는 사용자 안내·옵션·운영 경로의 재정비를 요청했다.

## 적용 범위
- 첫 실행 환영/연결/완료 안내를 캠페인 문서·자료 활용 중심으로 재작성. AI 연결은 선택 기능으로 안내.
- 별도 계정 화면을 AI 연결로 통합. 기본 화면은 사용할 AI와 접힌 추가 연결 영역. API 키·이 PC의 프로그램·다른 제공자는 이 영역에서 선택.
- 기존 로컬 AI 프로그램 감지와 웹 로그인/대화/메모리 동기화를 명확히 구분.
- 개발자 도구와 스킬은 펼쳐서 사용하는 영역으로 이동. 실제 명령어 `ieumoffice`는 외부 연동 호환성을 위해 유지.
- 자동 업데이트가 꺼진 배포 방식에 맞게 안정/베타 채널 선택을 제거하고 설치 파일 배포 안내 표시.
- 제품·공유 메뉴·피드 좌표와 패키지 홈페이지는 cheil-master/cheil-office로 통일. 자동 업데이트 정책은 계속 비활성 상태.
- 원본 Google 설문으로 가던 의견 보내기는 사용자가 직접 작성하는 Cheil 프로젝트 이슈로 변경. 앱에서 자동 제출하지 않음.
- 원본 제작자 메일을 제품 문의 주소로 사용하지 않도록 비움. 주소가 지정될 때까지 메일 버튼 미노출 및 메일 IPC에 빈 주소 보호.
- 시작/홈/연결/설정 도움말을 제품 전용 문구로 교체. 문서 엔진 사용법은 보존. 새 제품 문구는 21개 언어에 제공.
- 공통 AI 표시 그림을 문서 줄과 별 모양으로 교체하고 모든 편집기를 재빌드.
- README 한국어/영어를 현재 Cheil 기능과 배포 방식으로 재작성. 자체 MD 위키·캠페인 통합 저장소가 아직 설계 단계라는 점을 명시.

## 라이선스 화면과 출처
제품 정보에서 CheilOffice 배포본의 라이선스 열기 버튼과 접어서 읽는 고지 영역을 제공한다. NOTICE 앞에는 CheilOffice 배포 설명과 제품 지원 경로를 추가하고, 원본 고지·저작권·포함 라이브러리·글꼴의 고지를 보존한다. 기존 LICENSE를 새로운 권리 주장으로 덮어쓰지 않았다. 원본 기여자는 제품의 지원 운영자로 표시하지 않는다.
