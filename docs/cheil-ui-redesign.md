# Cheil Office UI 개편 — 2026-10-27

사용자가 확인한 클릭 시안을 실제 프로그램 UI에 적용한다. 작업 범위는 화면과 공통 폰트이며 문서 엔진, 저장 형식, AI 요청 정책은 변경하지 않는다.

- ‘워크스페이스’라는 별도 공간 이름 없이 ‘홈’을 사용한다.
- 홈에 기존 오피스 앱 8개를 모두 유지한다. Word·Excel·PPT·Markdown·HTML·마인드맵·한글·PDF의 기존 생성 콜백을 사용하며, 4개씩 2줄의 폴더 형태로 배치한다.
- 파일 열기·PDF 도구는 별도 버튼으로 유지한다. 홈의 최근 문서는 간결하게 표시하고, 전체 파일 화면에 형식 필터·검색·즐겨찾기·폴더 기능을 보존한다.
- 주 탐색은 홈·캠페인·지식·업무 도구·파일이다. 기존 자료 질문·에이전트·드라이브 등 보조 탐색은 사이드바의 펼침 영역에 보존한다.
- 업무 도구 8개는 홈과 도구 화면에서 고를 수 있다. 수식 도우미 6기능과 기존 AI 전송 금지선은 유지한다.
- 실제 캠페인 목록을 서류가 꽂힌 보관함 모양으로 표시한다. 빈 상태는 새 캠페인 버튼이며 가짜 캠페인이나 문서 수를 만들지 않는다. 기존 카드·타임라인·양식 생성·메일 기능을 유지한다.
- 사용자가 제공한 Cheil 원본 로고의 비율을 유지한다. 밝은 테마에는 검정 로고, 어두운 테마에는 흰 로고를 사용한다. 흰 로고의 검정 배경은 CSS screen 합성으로 처리하며 원본 파일은 수정하지 않는다.
- Pretendard Variable 1.3.9 원본과 OFL을 번들에 포함한다. 시스템에 폰트를 설치하지 않는다. 모든 편집기가 공통 UI 폰트·중립색 토큰을 사용한다. 문서 안의 명시적 글꼴과 저장 서식은 변경하지 않는다.
- 다크·라이트·시스템 모드는 기존 설정 API와 저장 방식을 사용한다. 탭은 40px 경계를 유지한 채 둥근 형태로 바꾼다. 문서 분할·탭 끌기·닫기 동작은 유지한다.
