# Pinterest 레퍼런스 기반 PPT 디자인

## 목적과 범위

참고 이미지의 텍스트 위치를 복제하는 대신, 시각적 위계·여백·정렬·도형의 역할과 페이지 종류별 구성 규칙을 저장한다. 첫 범위는 초안 → 표지·비교·과정 3장이다. 실제 이미지 해석과 내용별 생성에는 사용자가 선택한 AI 연결을 사용한다. 전용 Pinterest 세션은 기존 연결을 그대로 사용하며 별도 유료 Pinterest API를 추가하지 않는다.

## 사용

홈 → 내 양식 → 스타일 화면의 ‘레퍼런스로 PPT 디자인하기’를 연다. Pinterest 보드에서 이미지 1~2장을 선택하고 스타일 이름과 초안을 입력한다. 생성 버튼은 선택 이미지·초안·요청을 새 Slides 탭에 넘긴다. 연결이 없으면 편집기의 기존 전송 관문에서 중단하고 요청과 첨부를 남긴다.

이미지를 볼 수 있는 모델이 `define_reference_style`로 규칙을 먼저 저장한다. 텍스트·도형을 원본의 복사본이나 전체 이미지로 붙이지 않고, 기존 `generate_deck`의 표지·비교·과정 레이아웃과 페이지 스펙 생성기로 초안을 구성한다. 기존 레이아웃 검사와 렌더링 검수 경로를 유지한다. 모든 문서 변경은 기존 Slides 연산 경로를 따른다.

## 저장과 재사용

규칙은 userData/style-templates/ref-UUID.design.md로 저장한다. 위계, 구성, 도형 언어, 제외할 요소, 세 가지 페이지 레시피, 팔레트 및 선택 핀 URL을 담는다. 원본 이미지와 문구는 디자인 MD에 저장하지 않는다. 작업에 첨부한 이미지와 초안은 재시도·출처 추적을 위한 로컬 design-drafts 작업 폴더에 별도로 남는다.

MD는 사람이 읽는 설명과 `cheil-design-reference` JSON 블록으로 구성된다. 실제 적용 값은 이 검증된 JSON이다. 규칙을 편집할 때 아래 JSON을 수정하고 저장해야 한다. 설명문만 고치면 실행 규칙은 바뀌지 않는다. ‘MD 열기’로 편집·다른 이름으로 저장할 수 있고, ‘MD 가져오기’로 다른 파일을 새 디자인으로 등록할 수 있다.

저장 목록에서 디자인을 선택하고 새 초안을 입력하면 원본 이미지나 Pinterest 연결 없이 재사용한다. 생성 전에 편집기의 저장 스타일 선택에 연결하고, 동일한 규칙을 세 페이지 작성 단계에 전달한다. 저장 실패·첨부 거절 시 성공으로 표시하지 않는다. 첫 버전은 기존 PPT 전체를 객체 보존하며 재서식화하거나 Word에 적용하는 기능을 포함하지 않는다.

## 구현 위치

- Shell DesignStudio / PinterestPanel: 선택, 초안, MD 가져오기·재사용.
- Shell design-studio.ts / style-ipc.ts: 선택된 캐시 이미지 검증, 제한된 로컬 재료 준비, 기존 GenerateHandoff 호출.
- Slides shared/design-reference.ts / main/design-reference-store.ts: 의미 중심 규칙 검증과 정본 MD.
- Slides define_reference_style / template-selection-state / generate_deck: 분석 결과 저장 → 스타일 선택 → 내용별 구성.

## 검증의 구분

자동화 검사는 실제 계정 및 유료 AI 호출을 모방하지 않는다. 합성 Pinterest 응답으로 UI/IPC를, 모델 출력 모형으로 MD 저장 및 생성 경로의 전달을 확인한다. 샘플 PPT는 같은 페이지 스펙 생성 엔진으로 직접 구성한 시각 검수 예시다. 실제 Pinterest 이미지를 AI가 분석해 생성한 결과라고 표시하지 않는다.

Pinterest 검수 프로필에는 AI 제공자 키가 설정되어 있지 않았다. 이 상태에서는 실제 모델의 이미지 해석 정확도와 최종 자동 디자인 품질을 검증하지 못한다. 연결된 이미지 이해 모델로 실사용 검수가 추가로 필요하다.
