# Cheil Office 독립 엑셀 수식 도우미

2026-10-27. 사용자는 수식 도우미를 기존 엑셀 편집기 AI와 별도로 유지하기로 했다. 일반 엑셀 작업이 중심이며 광고 업무는 보조 예시다. 참고 서비스의 일반적인 기능 범위와 입력/결과 흐름을 참고하고, 소스·그래픽·고유 문구를 복제하지 않고 작성했다.

## 사용 흐름

홈 왼쪽 업무 도구 → 엑셀 수식 도우미. 상단에서 Excel 버전과 작업을 선택한다. 수식 만들기·데이터로 만들기·설명·오류 해결·개선은 사용자가 요청할 때만 기존 `ai:chat`과 선택된 AI 설정을 이용한다. 데이터 입력은 실제 파일이나 열린 시트와 연결되지 않는다. 함수 사전은 AI 호출 없이 동작한다.

## 설명과 선택을 돕는 기능

- 필요한 정보가 없으면 AI가 추가 질문을 반환한다. 답변을 적으면 원래 요청·답변 이력을 포함해 다시 요청한다. 입력을 고쳤다면 이전 답변의 복사와 후속 요청을 막고 새 요청을 받는다.
- 추천 수식과 유의미한 대안을 비교한다. 선택할 상황, 장단점과 호환 버전을 함께 표시하고 각각 복사할 수 있다.
- 수식 해부는 AI가 제공한 구문 중 실제 수식에 들어 있는 부분만 표시한다. 누르면 해당 구문을 강조한다. 수식이나 문서의 HTML을 실행하지 않는다.
- 오류 해결·개선은 요청 당시의 기존 수식과 제안 수식을 비교한다. 공통 앞뒤 문자를 제외한 변경 범위는 로컬에서 계산한다. 변경 이유와 결과 영향 설명은 AI의 예상이며 계산 검증을 뜻하지 않는다.

## 데이터 입력과 전송

최대 20행·8열의 샘플을 직접 적거나 Excel에서 복사해 붙여넣는다. 인용된 탭·줄바꿈과 이중따옴표가 있는 TSV를 처리한다. 크기나 셀 주소가 잘못된 입력은 잘라서 보내지 않고 거절한다. 표 시작 셀과 결과 셀은 A1 방식으로 지정한다.

기본 요청은 열 이름·범위·행 수만 포함한다. 샘플 값은 체크할 때만 포함한다. 첫 행을 열 이름으로 사용하지 않으면 기본 요청에는 그 행의 값도 넣지 않는다. 작업 설명과 별도로 사용자가 직접 적은 문맥은 요청에 포함된다. 제공자 선택과 외부 전송 판단은 기존 공용 경로를 따른다. AI가 수식에 필요한 셀 참조·상수를 그대로 사용해야 하므로 일반 번역 도구처럼 숫자를 치환하지 않는다.

## 함수 사전

합계·통계, 조건·논리, 찾기·참조, 텍스트, 날짜, 배열의 28개 함수를 이름·용도로 검색한다. 정의와 버전 표시는 [Microsoft 공식 함수 목록](https://support.microsoft.com/en-us/excel/excel-functions-alphabetical)을 기준으로 확인했다. 기본 구조와 사용 예시는 독립적으로 작성했다. 지원 표시는 이 도구의 선택 가능 버전 범위 기준이다. 예를 들어 XLOOKUP은 Excel 2019에서 대안 필요, 2021에서 지원으로 표시한다. TEXTJOIN은 2016에서 대안 필요, 2019에서 지원이다. 함수 사용 버튼은 입력만 채우며 AI를 자동 호출하지 않는다.

## 구현과 검증

화면은 `FormulaTool.tsx`, `FormulaDataTable.tsx`, `FormulaDictionary.tsx`, `FormulaResult.tsx`, `FormulaTool.css`에 나눴다. 순수 함수는 `tools/formula-{tools,table,dictionary,words}.ts`에 있다. 모두 `apps/shell/src/renderer/src/cheil` 아래다. 문서 엔진·제공자 선택·키 저장 경로는 변경하지 않았다.

타입 검사·ESLint·개발 빌드·단위 시험 25개가 통과했다. 최종 가짜 API 앱 시험 5개도 모두 통과했다. 앱 시험은 여섯 작업 및 기존 업무 도구, 복사, 추가 질문, 손상된 응답 복구, 붙여넣기, 전송 기본값, 버전별 함수 안내를 검증했다. 복사 시험은 비동기 완료 대기 후 확인하도록 수정했다. 실제 앱의 새 화면과 시험 캡처를 검토했다.

실제 AI의 수식 정확성·동등성은 확인 필요다. 이 도구는 수식을 실행하지 않으며 실제 Excel에서 확인해야 한다. 설치 파일 재생성·설치·커밋·푸시는 하지 않았다.
