# 현업 샘플 기반 템플릿 개편

2026년 10월 26일. 사용자가 지정한 로컬 폴더의 17개 문서를 유형별로 분석했다. 문서의 본문은 로컬에서 처리하고 반복 항목과 구조만 추출했다. 텍스트가 부족한 PDF 380쪽은 Windows OCR로 보완했다. OCR은 오인식할 수 있으므로 낱말 출현만으로 모든 문서의 필수 항목이라고 단정하지 않았다. 실제 광고주명, 수치, 이미지, 로고는 결과물에 포함하지 않았다.

## 결과물

- OT 및 킥오프 PPT 12장: 표지, 과제, 시장·지난 캠페인 리뷰, 타깃, 메시지·RTB, 캠페인·소재 역할, 크리에이티브 방향, 소재별 제작 요청, 레퍼런스, 산출물, 일정, 확인 사항과 다음 할 일.
- 컨택리포트 Word: 회의 기본 정보, 주요 결정과 미결 사항, 안건별 상세 피드백, AE 의견, NEXT, 추가 확인 사항. 빈 양식은 Word에서 2쪽이며 내용에 따라 늘어난다.
- 미디어브리프 Excel: 한 시트, 6개 구역. 집행안을 요청하는 문서이므로 기존 매체 믹스·CPM·CPV 계산 중심 플랜을 제거했다. 계산을 위한 데이터가 없는 빈 브리프에 임의의 수치나 계산식을 만들지 않았다.
- 결과보고서 PPT 11장: 표지, 결과 요약, 캠페인 개요, 미디어 운영, 목표 대비 성과, 매체별 결과, 소재별 성과, 타깃·접점 성과, 소비자 반응, 배운 점과 다음 제안, 데이터 기준.

## 사용 기준

공통 값은 앱의 칸 사전 이름을 그대로 쓴다. 그 외 칸은 문서 안에서 서로 다른 이름을 쓴다. 자료가 없으면 `[확인 필요]`로 남긴다. 선택 장은 사람이 필요 여부를 판단한다. AI가 자동으로 선택 장을 삭제하거나 소재별 장을 늘린다고 보장하지 않는다. 기존 앱의 빠른 채우기에서는 정해진 칸만 채운다.

## 교체 범위

앱의 기존 Cheil 내장 양식 6종을 제거·교체하여 요청한 4종만 남긴다. 사용자 개인 파일, 내 양식 등록 자료, 캠페인 폴더, 원본 샘플은 교체 대상이 아니다. 앱 내부 스킬 식별자는 호환성을 위해 유지한다. 캠페인 제안서와 경쟁 PT 분석의 내장 스킬은 삭제한다.

## 검증 결과

- PPT 23장 전체 이미지 검수 및 패키지·글꼴·슬라이드 크기·재열기 검사 통과. 실제 앱에서 12장·11장 열기 통과.
- Word 실제 Microsoft Word PDF 출력 2쪽 검수. 앱에서 기본 정보·피드백·NEXT 인식 확인.
- Excel 전체 사용 영역 이미지 검수. 앱에서 셀 내용 읽기와 캠페인 공통 정보 채우기 통과.
- 검증 완료: shell 빌드·타입 검사, 변경 코드 ESLint, 단위 시험 49개(UI 24·shell 24·slides 1), 새 양식 열기·캠페인 정보 채우기·변경 전파·내 양식 등록 등 통합 시험 17개 통과. API 미연결 안내 시험 1개는 이 PC의 구독 상태를 격리한 뒤 별도 재실행하여 통과했다. 원본 샘플과 실제 API 키는 시험에 사용하지 않았다.
- Electron 녹화가 연결을 멈추는 환경이어서 `GENOFFICE_E2E_NO_VIDEO=1`로 화면 캡처만 수행했다. 이 선택 옵션을 시험 도우미에 추가했다.
- 변경 파일 서식 검사를 수행했다. `check-english-comments`는 삭제된 추적 파일을 읽으려다 중단하는 기존 도구 동작으로 완료하지 못했다. 병합 전 전체 검사와 실제 API 결과 품질은 확인 필요.
- 설치 파일은 새로 만들거나 설치하지 않았다. 커밋·푸시하지 않았다. 프로젝트 개발 빌드에 반영한 상태다.
