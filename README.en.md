# CheilOffice

A Windows desktop office for campaign documents and reusable planning materials.

## Available now

Open and edit DOCX, XLSX, PPTX, PDF, Markdown, HTML, XMind and HWP documents. Start from four agency templates, manage campaign cards and timelines, and use the formula assistant and work tools. The own Markdown wiki works without Obsidian: import files or text, search, edit and restore versions. Campaigns link the same material without duplicating it.

Campaign questions use only linked excerpts. AI answers can be reviewed and saved as draft wiki pages. Obsidian is optional; existing vaults are not moved. The default store is Documents/Cheil 위키 and can be changed in Options. See docs/cheil-wiki.md.

## AI connections

Writing and reading documents do not require AI. Select an AI connection in Settings for AI tasks. API connections follow the provider's usage terms and billing. Local program connections use supported programs' existing sign-in. Browser sessions, chat history and memory are not synchronized.

Some AI tasks send relevant material to the selected provider. Read the connection notices and check generated content before using it.

## Distribution and support

Windows x64 installers are named `CheilOffice-Setup-<version>.exe`. Automatic updates are disabled; new versions are supplied as installers.

Project: https://github.com/cheil-master/cheil-office

Feedback: https://github.com/cheil-master/cheil-office/issues

Developer tools retain the `cheiloffice` command for integration compatibility.
