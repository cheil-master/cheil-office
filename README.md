# Cheil 기획 오피스

캠페인 문서와 업무 자료를 한곳에서 작성하고 다시 찾는 Windows 데스크톱 오피스입니다.

## 현재 사용할 수 있는 기능

- Word·Excel·PPT·Markdown·HTML·마인드맵·한글·PDF 문서를 열고 편집합니다.
- OT 및 킥오프, 컨택리포트, 미디어브리프, 결과보고서 양식을 제공합니다.
- 캠페인별 기본 정보, 메모와 작업 이력을 관리합니다.
- 수식 도우미, 맞춤법·글자수, 금액·부가세, 날짜 계산, 번역, 메일 초안과 PDF 도구를 제공합니다.
- My Wiki에서 파일·붙여넣은 글을 자체 Markdown 저장소에 보관하고 검색·편집·이력 복원합니다.
- 캠페인 자료는 같은 위키 자료를 연결해 사용합니다. 하나의 자료를 여러 캠페인에서 재사용하며, 연결 해제는 원문을 지우지 않습니다.
- AI 질문은 선택한 캠페인에 연결된 관련 발췌만 사용하고, 검토한 답을 위키 초안으로 저장할 수 있습니다.

Obsidian은 선택 연결입니다. 기본 저장 위치는 문서 폴더의 `Cheil 위키`이며 옵션에서 변경할 수 있습니다. 기존 볼트는 자동 이동하지 않습니다. [위키 사용과 데이터 보존](docs/cheil-wiki.md)을 참고하세요.

## 광고대행사 업무 지식 관리

My Wiki에서 원자료와 정리된 업무 지식을 관리하고, 새 회의록·보고서를 기존 지식과 비교합니다. 변경 제안은 항목별로 반영·보류·거절하며 반영 로그와 원문 이력을 보존합니다. 질문은 관련 근거로 답변하고, 사용자가 확인한 결과를 본인의 카카오톡 나와의 채팅으로 보낼 수 있습니다. 카카오 연결은 사용자별로 설정하며 한 번에 200자까지 전송합니다.

## AI 연결

문서 작성·읽기에는 AI 연결이 필요하지 않습니다. AI가 필요한 작업은 설정의 **AI 연결**에서 사용할 연결을 고릅니다.

- API 키: 선택한 제공자의 API를 사용하며 해당 제공자의 비용과 이용 조건을 따릅니다.
- 이 PC의 AI 프로그램: 지원되는 프로그램이 설치·로그인돼 있을 때 연결 상태를 확인합니다. 웹 ChatGPT의 로그인 쿠키나 대화·메모리를 동기화하는 기능이 아닙니다.
- 추가 연결과 개발자 옵션은 필요한 경우에만 펼칩니다. 선택한 연결에서 문제가 발생해도 다른 유료 제공자로 자동 전환하지 않습니다.

AI 작업에서 자료 일부가 선택한 외부 제공자로 전달될 수 있습니다. 실제 업무 자료를 사용하기 전 설정과 안내를 확인하세요. AI 결과의 근거와 정확성은 확인해야 합니다.

## 설치 및 배포

Windows x64용 `CheilOffice-Setup-<version>.exe`를 사용합니다. 새 버전은 설치 파일로 배포하며 자동 업데이트는 꺼져 있습니다. 사내 PC의 실행·설치 허용 여부는 해당 PC에서 확인해야 합니다.
